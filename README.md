# ⚾⛏️ 國小二年級期中考：雙版本 3D 互動複習系統（實況棒球版 ＆ 麥塊體素版）

專為**臺灣 108 課綱國小二年級上學期（7～8 歲學童、陪讀家長與指導教師）**打造的**雙版本 3D 互動複習遊戲**與**結構化紙本考卷題庫系統**。兩套遊戲（`index.html` 棒球版與 `minecraft.html` 麥塊版）並存且**錢包、神兵與錯題庫完全獨立計算**，底層共用 **150 題精準命題題庫（國語 50 題＋數學 50 題＋生活 50 題）**與蘇格拉底三階段引導式教學，並支援 **PWA 離線快取**。

## 🚀 雙版本核心功能亮點（紀錄獨立計算）

### ⚾ 版本一：3D 實況滿貫王 5.0（`index.html`）
1. **3D 實況棒球場與三大魔王階段**：
   - 依局數推進動態切換「晴空白晝（暴熊隊長）$\rightarrow$ 魔幻夕陽（閃電忍蛙）$\rightarrow$ 大聯盟星光夜賽（黃金巨龍）」。
   - 獨立金幣錢包（`g2_baseball_coins`）、4 把 3D 特效神兵球棒、球探透視刪去卡、巨砲必殺覺醒與 Statcast 飛行距離測速。
2. **學科專屬棒球互動機制**：
   - **好球帶九宮格投球靶心**：3×3 九宮格靶板模式，擊碎正確答案靶心。
   - **外野邊線爭議・互動式斷尺量測台**：數學第 3 單元自動浮現非零起點斷尺與「🐸 一格一格跳大格」圓弧動畫鷹架。
   - **盜壘衝刺・兩步驟跑壘連鎖**：數學第 4 單元兩步驟應用題自動啟動「先算第一步中間量盜上二壘（+10💰），再揮棒算第二步衝回本壘」。
   - **☀️ 球場光與影子互動實驗室**：生活科第 2 單元自動啟動，可切換早晨太陽在東、中午 12 點正上方、傍晚太陽在西與手電筒靠近，即時觀察打者影子方向與長短變化。
   - **客製化 3D 球衣背號與 MVP 球員卡下載**：`THREE.CanvasTexture` 即時印製球衣背號，賽後一鍵下載高解析 PNG 傳奇球員卡。

### ⛏️ 版本二：3D 麥塊大冒險・終界屠龍篇（`minecraft.html`）
1. **Three.js 3D 體素（Voxel）世界與三大維度 BOSS**：
   - 採用 `THREE.NearestFilter` 零模糊像素程序貼圖，隨第 1～9 波推進自動切換「🌲 主世界草原（巨型苦力怕）$\rightarrow$ 🔥 地獄下界堡壘（烈焰使者王）$\rightarrow$ 🐉 終界黑曜石之島（終界巨龍）」。
   - 獨立綠寶石錢包（`g2_mc_emeralds`）、4 把 3D 體素武器（木鎬、鐵劍、附魔鑽石劍、獄髓神鎬）、終界之眼透視、TNT 爆破與經驗值（XP）等級條。
2. **學科專屬麥塊紅石與合成台機制**：
   - **3×3 工作台合成九宮格（`CraftingTableGrid`）**：將選項打散入 3×3 合成槽，放對材料觸發鐵砧合成音效。
   - **紅石活塞斷尺測量台（`RedstonePistonRuler`）**：數學第 3 單元自動呈現紅石活塞推桿與史萊姆方塊跳格動畫。
   - **動力鐵軌礦車兩步驟連鎖（`MinecartRailChain`）**：數學第 4 單元先點亮第一段動力鐵軌（+10💎 綠寶石），再衝向終點寶箱。
   - **☀️ 麥塊方塊日晷與紅石光影實驗台**：生活科第 2 單元自動浮現，切換方塊太陽時間或紅石火把距離，觀察勇者方塊影子拉長或縮短。
   - **客製化披風編號與麥塊英雄卡 PNG 下載**：3D 勇者背後即時繪製像素披風號碼，結算可匯出像素風「終界屠龍英雄卡」。

### 🧙‍♂️ 共用核心：蘇格拉底三階段引導教學 ＆ A4 考卷列印器（含弱點雷達分析）
- **蘇格拉底三階段引導式教學**：第一次答錯不直接判出局也不洩漏答案，提供「迷思診斷 $\rightarrow$ 關鍵字思考提問 $\rightarrow$ 遮罩式算式/語意小錦囊（`【 ❓ 】`）」。
- **線上動態組卷、A4 紙本考卷列印器與📊弱點單元雷達分析儀（`print-exam.html`）**：支援依三科、18 大單元專項、「🎯 雙版本綜合錯題訂正卷」動態組卷列印，並自動統計學童在 8 大核心觀念區段的錯題分佈與陪讀建議。
- **PWA 離線快取支援（`sw.js` ＆ `manifest.json`）**：快取雙版本 3D 引擎與 150 題題庫，無網路環境也能流暢遊玩與列印考卷。

## 🛠️ 本地運行與自動化檢驗

1. **啟動本地遊戲與列印系統**：
   使用任意靜態伺服器開啟專案根目錄（例如 `npx serve .` 或 VS Code Live Server），瀏覽器開啟 `index.html` 即可遊玩，點擊右上角「**🖨️ 考卷列印**」可開啟 `print-exam.html`。
2. **執行題庫與防洩題自動化檢測**：
   ```bash
   node scripts/validate-questions.mjs
   ```
